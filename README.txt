Hisab Book (হিসাব বুক) — টাকার লেনদেন হিসাব ওয়েব অ্যাপ্লিকেশন — ভার্সন ১.৩

ফাইল: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

GitHub Pages-এ প্রকাশ (repository নাম: hisab-book):
1. GitHub-এ নতুন repository খুলুন, নাম: hisab-book (Public)।
2. জিপের ভেতরের সব ফাইল (ফোল্ডার নয়) repository-র মূল স্তরে আপলোড করুন।
3. Settings → Pages → Branch: main, Folder: /(root) → Save।
4. কিছুক্ষণ পর https://আপনার-ইউজারনেম.github.io/hisab-book/ লিংকে অ্যাপ চালু হবে।

আপডেট দিলে: নতুন ফাইল আপলোড করুন; sw.js-এর প্রথম লাইনে 'hisab-book-v4' বদলে 'hisab-book-v5' করুন।

ব্যাকআপ: তথ্য ব্রাউজারের localStorage-এ থাকে। নিয়মিত "CSV ব্যাকআপ" নিন, রিস্টোরে "CSV ফাইল বেছে রিস্টোর" ব্যবহার করুন।
